## Ввод/вывод данных

### Вывод данных функция `print()`

Для вывода данных на экран используется функция `print()`. Если нужно вывести строковые данные то нужно ставить кавычки `' или "` `print("Привет, мир")`. Если аргументов много, то они перечисляются через запятую. `print('Hello', 'World')`. 

Между аргументами автоматически ставится пробел. Если вместо пробела нужен другой разделитель, то в конце приводится аргумент `sep`: `print('1', '2', '3', sep = '+')` выведет `1+2+3`. Разделитель может быть строкой, переменной или отсутствовать при `sep = ''`.

По умолчанию после `print()` происходит перенос строки `/n`. Параметр `end` позволяет изменить конец строки на переменную, строку или убрать совсем по аналогии с `sep`.

Каждая последущая функция print выводит данные на новую строку

`
print('Hello')
print('World')
`

Выведет 

`
Hello
`

`
World
`

`print()` без аргументов вставляет новую пустую строку

### Ввод данных функция `input()`

`name = input()` - присвоит введенное значение переменной name

`print('Hello', input())` -  запросит ввести данные и выведет их на экран вместе со словом `Hello`

`name = input('Как тебя зовут?')` - Сперва выведен на экран текст, затем попросит ввести данные с клавиатуры, а затем присвоит их переменной `name`

## Условные операторы

### Операторы if elif else

Опреаторы `if`, `elif` и `else` работают также как и в СИ. Код который должен выполниться после оператора выделяется отступом в 4 пробела (1 таб).

```
answer = input('Какой язык программирования мы изучаем?')

if answer == 'Python':
    print('Верно! Мы ботаем Python =)')
    print('Python - отличный язык!')
else:
    print('Не совсем так!')
```

### Логические операторы and, or, not
 
Оператор `and` - логическое и.  

```
age = int(input('Сколько вам лет?: '))
grade = int(input('В каком классе вы учитесь?: '))
city = input('В каком городе вы живете?: ')
if age >= 12 and grade >= 7 and city == 'Москва':
    print('Доступ разрешен.')
else:
    print('Доступ запрещен.')
```

Оператор `or` - логическое или.

```
city = input('В каком городе вы живете?: ')
if city == 'Москва' or city == 'Санкт-Петербург' or city == 'Екатеринбург':
    print('Доступ разрешен.')
else:
    print('Доступ запрещен.')
```

Оператор `not` - логическое отрицание.

Следущий код:

```
age = int(input('Сколько вам лет?: '))
if not (age < 12):
    print('Доступ разрешен.')
else:
    print('Доступ запрещен.')
```

Полностью эквивалентен:

```
age = int(input('Сколько вам лет?: '))
if age >= 12:
    print('Доступ разрешен.')
else:
    print('Доступ запрещен.')
```

У логических операторов также есть свой приоритет, в порядке убывания: `not` - наивысший, `and` - средний, `or` - наименьший

### Числовые типы данных

Для преобразования к типу данных с плавающей точкой используют функцию `float()`

```
num = float(input())  # преобразование считанной строки в число с плавающей точкой
```

При этом можно также использовать явное преобразование, например числа _float_ в _int_

```
num1 = 17.89
num2 = -13.56
num3 = int(num1)
num4 = int(num2)

print(num3)
print(num4)
```

этот код выведет:

```
17
-13
```
